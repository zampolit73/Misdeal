# System Dialog V1 — player-approved visual direction

The player requested the same appearance as the existing main menu and approved the concept on 2026-11-26. The archived WebP is the approved generated reference, not an in-engine screenshot or runtime background. Production builds the panel and live labels/buttons from the actual Main Menu V2 secondary/primary plate textures, preserving their original bronze bevel, dark stone and muted burgundy. The same family applies to the return-to-main-menu confirmation.
