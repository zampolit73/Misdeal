# Misdeal Intro V2 — Art Pack

Утверждённая визуальная последовательность сюжетного вступления из шести кадров. Первые пять сохраняют исходный сюжет; шестой связывает место встречи героя и Волшебника с существующим залом выбора героя. Все изображения чистые, без текста, кнопок и рамок.

## Состав

- `runtime/frame_01.webp` … `runtime/frame_06.webp` — RGB WebP, 1280×720, готовые к импорту. Размер соответствует прежнему вступлению.
- `masters/frame_01.png` … `masters/frame_06.png` — неизменённые оригиналы, 1672×941.
- `intro_dialogue.json` — исходные русские реплики кадров 01–05, новая утверждённая реплика кадра 06.
- `manifest.json` — порядок кадров, размеры, контрольные суммы SHA-256, происхождение. Не является runtime-зависимостью.
- `sequence_preview.webp` — обзор последовательности, только для проверки.
- `CODEX_PROMPT.md` — готовая задача для внедрения.

## Визуальный контракт

Кадры 01–05 происходят в собственном доме пожилого героя, в иной местности, не в замке первого акта. Уютный, но мрачный сельский интерьер. Одна и та же внешность героя, каноническая внешность Волшебника, постоянные предметы обстановки. Приглушённый свет, тёмная древесина, состаренная бронза, бордовая ткань. В кадре 06 жилище растворяется и проступает знакомый зал, в котором начинается выбор героя. Не добавлять новый замок или иные локации, не менять рисунки, не генерировать новые варианты.

## Технический контракт

- Целевой каталог: `assets/pixel/intro/visual_v2/`. Существующие кадры остаются для совместимости и отката.
- Исходники и документацию сохранить в `assets/source_archive/intro_v2/` по действующим правилам проекта.
- Реальные надписи, кнопка пропуска, подсказка управления и затемнение — отдельные Godot Control-узлы. Не рисовать текст поверх WebP и не применять прозрачный hotspot вместо видимой кнопки.
- Порядок 01→02→03→04→05→06→существующий ClassSelect. Без изменения сохранений, механик, Hero Select, диалогов 01–05 и правил нового забега.
- На 1280×720 использовать свободные области кадров: сверху — компактный текст, область персонажей, карты и руки не закрывать. Для 04 учесть более крупный план и шесть карт; не требовать одинакового положения панели во всех шести кадрах. UI необходимо проверять на реальном рендере.
- Щелчок, Space, Enter и Esc сохраняют прежние значения. Пропуск ведёт прямо к ClassSelect; последняя подсказка появляется только на кадре 06. Между 05 и 06 — короткая плавная смена, после 06 — мягкое затемнение и существующий роутер.
- Пакет проверен технически (размеры, декодирование, SHA-256); импорт и нативный запуск Godot ещё не выполнялись.
