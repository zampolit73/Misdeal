# Cursed Deck V2 — user-approved art direction (26 Nov 2026)

`approved_reference.webp` is the generated card design the user approved, based on the physical worn card shown at the top of the live Fate Spread discard stack. It is illustrative, not a native capture. The separate clean front, back and unmarked unknown card bases are cropped from a generated sprite sheet derived from this board; runtime assets are at `assets/pixel/ui/cursed_deck_v2/`. Existing art and Russian UI text are supplied separately in Godot.
