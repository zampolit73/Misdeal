# Misdeal — Reward Cinematics 1.0 · Elite Artifact

Арт-пакет для `elite_artifact` / «Трофей стража», не реализация Godot. Утверждённый концепт находится в `approved_reference.png`; чистая художественная адаптация — `source/clean_master.png`. Игровые ресурсы — только `runtime/`. Чистая подложка 1280×720 не содержит текста, реликвий или цифр. Варианты preview — исключительно проверка расположения живого текста, зоны арта помечены намеренно. Не импортировать previews как runtime.

## Подключение
- `runtime/artifact_reward_plate.webp`: базовая сцена, три пустых физически существующих ниши; не накладывать ещё одну рамку.
- `layout_1280x720.json`: абсолютные Rect2 x/y/w/h, шрифты, цвет, выбор позиций, имена текстур.
- `runtime/states/slot_N_hover.png`, `slot_N_selected.png`: прозрачная локальная коррекция яркости бронзовой рамки. Не менять общий фон.
- `slot_N_inactive.webp`: глухое затемнение неиспользуемой ниши, без мыши, фокуса и подписи; не показывать как доступный вариант.
- `confirm_button_*.webp`: точные кропы с подложки для состояний; текст выводить отдельным Label.

## Данные и варианты
Использовать текущий `scripts/reward/reward.gd`, `_setup_elite_reward()`, `option_ids`, `RunState.get_available_artifact_ids()`; сохранить порядок, доступность, все условия и текущий fallback `elite_gold` (+50 золота). Ничего не выбирать/перемешивать дополнительно. Только до трёх предложений. 1 вариант — в центре, 2 — крайние ниши, 3 — все. 0 реликвий — центральный вариант «Опустевший тайник» с текущим `empty_cache` и кнопкой «Забрать золото». Для 1/2 вариантов пустые ниши затемнены.
Все 13 реальных изображений брать через `ArtifactArtCatalog.get_reliquary_texture(artifact_id)` (у `get_texture` только 4 legacy-изображения); применять keep-aspect-centered и nearest filtering, не растягивать маленькие предметы без необходимости. Текст — из `ArtifactData.title` и `description`; название и описание не заменять демонстрационными текстами, не добавлять придуманные показатели. Сохранить текущую реплику, включая предупреждение про долг. Переносить длинные тексты, при необходимости прокручивать описание, не уменьшать ниже 15 px. Декоративные узлы mouse_filter=IGNORE.

## Выбор и подтверждение
Отдельная кнопка в утверждённом концепте означает локальный preview-выбор и единственное подтверждение. Выбор карточки не начисляет награду; подтверждение вызывает существующий обработчик `_on_reward_button_pressed(index)` с настоящим индексом option_ids (не индексом физической ниши). Изначально выбран первый доступный вариант. Мышь, стрелки, клавиатурный фокус, Enter на кнопке. На карточке Enter выбирает и переводит фокус к кнопке. ПКМ сохраняет существующий просмотр деталей. Во время commit блокировать все варианты и кнопку; повторный клик не выдаёт награду, при отклонённом выборе восстановить доступность. Не менять `RunState.add_artifact`, `_resolve_elite_option`, `_finish_reward`, сохранения, переходы, Archive, баланс. Сохранять обычный выход из деталей и прежние правила Esc.

## Внедрение
Только `elite_artifact`. При выходе из режима восстановить прежние UI nodes и стили, не затронуть `normal_loot`, `major_upgrade`, `bonus_upgrade`, `death_wager`. Отдельные UI-ноды предпочтительнее переписывания reward flow.
Минимальный QA: 0/1/2/3 предложений, длинное описание, выбор и подтверждение мышью/клавиатурой, однократная выдача и переход, настоящая запись в Архив, fallback +50, major_upgrade → elite_artifact, normal_loot без регрессий. Изолированный профиль. Реальные скриншоты Godot 1280×720.

## Статус
Чистая подложка создана на основе утверждённого концепта средствами генерации изображения; состояния и координаты подготовлены программно. Проверены размеры файлов, композиция и переносы трёх реальных описаний в растровых previews. Нативная проверка Godot не выполнялась. Реальные предметы не включены в ZIP — они уже в репозитории и подключаются из каталога.
