# Misdeal — Run Chronicle Visual V2

Пакет для Godot 4.7.x. Утверждённый пользователем художественный концепт: `source/approved_reference.png`. Новый чистый мастер создан на его основе; верхняя навигация в runtime-подложке переиспользована из утверждённого Bestiary V2. `layout_preview.webp` — статическая проверка координат, НЕ скриншот Godot: буквы и номера в иконках являются обозначениями областей, их заменяют настоящие портреты и изображения.

## Внедрение

- Разместить runtime в `assets/pixel/ui/wizard_chronicle_v2/`, JSON рядом; source и provenance сохранить в `assets/source_archive/wizard_chronicle_v2/`.
- Использовать `chronicle_plate.webp` только для вкладки 2 (Летопись). Верхние вкладки и заголовок имеют те же координаты, что в Bestiary V2. Не менять остальные вкладки. Все надписи и элементы управления живые.
- `layout_1280x720.json` задаёт экранные координаты. Пять записей на странице, новые сверху. Даты из record.date. Пустые строки неактивны; нет записей — понятное пустое состояние. Статическая декоративная вертикальная рейка не является скроллбаром; навигация — живые кнопки страниц.
- В `WizardArchive.history` уже есть `won`, `role`, `party`, `card`, `relics`, `style`, `oath`, `last_deal`, `date`. Использовать их без миграции и без записи в профиль при просмотре. `card` — достигнутая карта, не число завершённых карт. Сортировать по дате, сохранять правильное соответствие записи. Не рисовать победу до XIII.
- Использовать утверждённые портреты героя из текущего каталога проекта, `ArtifactArtCatalog.get_reliquary_texture` для реликвий. Не создавать фиктивные предметы; 13 областей справа позволяют показать все. При длинных названиях — wrap и tooltip без перекрытия печати; пустые области скрыть.
- Декоративный пейзаж и печать не являются фактическим маршрутом забега. Показывать I–XIII с выделением достигнутой карты (не выдумывать события, бои и состояние каждой карты). Стиль и клятва — реальные названия из RunCharter; last_deal — фактический bool. Не выводить не сохранённые золото, длительность, убитых врагов, здоровье или количество событий.
- Выбор мышью и клавиатурой, страницы, Esc, переключение вкладок. Проверить 0 записей, победу XIII, поражение, >5 записей и 13 реликвий на изолированном профиле. Godot 1280×720, скриншоты, короткая проверка, отдельная ветка/PR до визуального утверждения.
