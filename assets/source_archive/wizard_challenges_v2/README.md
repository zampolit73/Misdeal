# Misdeal — Challenges Visual V2

Художественный пакет для вкладки «Испытания» (четвёртая вкладка Архива). Утверждённый концепт — `source/approved_reference.png`, чистый master — `source/challenges_master.png`. `runtime/challenges_plate.webp` — чистая подложка 1280×720 с верхней навигацией, взятой без изменений из пакета Летописи. `layout_1280x720.json` — точные координаты (x,y,w,h); пути относительны runtime.

`runtime/seals` — вырезанные из утверждённого концепта эмблемы, открытая/закрытая версия каждого из 12 пунктов. `runtime/details` — крупные сургучные печати с теми же символами. `states/seal_selected.png` — прозрачная подсветка выбора; `states/tab_*_active.webp` — существующие утверждённые вкладки. Картинки содержат только декоративные неизменяемые символы, включая римские номера клятв; тексты, открытость, счётчик и выбор живые. `layout_preview.webp` — проверочная компоновка, НЕ захват Godot, иллюстративный логически возможный профиль (4/12). Не импортировать как игровой экран.

## Настоящие данные

Использовать `WizardArchive.history`, `style_unlocked(role)`, `highest_oath()`, `RunCharter.STYLES` и `OATHS`, существующие условия `_show_challenges()`.

3 стиля: blood_oath (knight), shadow_hunter (ranger), ash_seer (mage). Условие — победа над XIII соответствующим главным героем. Эффект — `STYLES[role][2]`.

4 достижения: solo_xiii (победа и party.size()==1), trio_xiii (победа и party.size()==3), no_last_deal (победа без Last Deal), oath_v_victory (победа с V). У достижения нет отдельного боевого бонуса: не выдумывать его, вместо «Эффект» можно показать статус выполнения или «Без дополнительного игрового эффекта».

5 клятв: oath_1..oath_5. Доступность — rank <= highest_oath(). I открывается после первой победы; II–V по существующей последовательности. Открытая клятва НЕ означает победу с ней. Отдельное достижение oath_v_victory использует именно факт победы. Эффекты — `OATHS[rank][1]`. Сохранять условия существующего проекта без изменений.

Итоговый счётчик — сумма 12 реальных булевых состояний; никакой фиксации числа из концепта. У закрытых печатей условия и описание остаются читаемыми. Длинные описания переносятся, при необходимости компактный скролл внутри прямоугольника.

## Внедрение

Сохранить существующие три утверждённые вкладки, shared navigation, клавиатуру и Esc. Не менять формат профилей, механику, выбор стиля/клятвы или RunState. Печатям соответствуют настоящие кнопки, невидимые стилевые рамки, текстовые узлы и отдельные TextureRect. Никакого текста, впечённого в подложку. `approved_reference.png` и исходный master хранить в source archive, runtime — в отдельном каталоге игры.

Проверить Godot 1280×720 в изолированных профилях: 0/12, частичный прогресс и полный; доступная, но не пройденная клятва V и победа с V должны различаться. Навигация, фокус, Esc, отсутствие записи при просмотре. Сравнить с референсом, не запускать массовый QA.
