# MISDEAL — Death Wager Reward Visual V1.2

Утверждённая композиция «ВЫИГРЫШ СТАВКИ» подготовлена для нативного интерфейса. Не перерисовывать и не подменять загруженный арт.

## Состав и назначение
- `approved_reference.png`: точный утверждённый концепт V1.2; только референс, содержит примерные надписи и предмет.
- `clean_master.png`: очищенный мастер V1.2; сохранены канонический волшебник, фон, рамки, пергамент и кнопочные пластины, удалены все надписи и заполнение трёх окон арта.
- `runtime/wager_plate.webp`: 1280×720, чистый фон.
- `runtime/gold_windfall.webp` и `runtime/bonus_upgrade.webp`: технические кропы утверждённых иллюстраций из утверждённого V1.2. Оконный фон входит в кроп; без текста и внешней рамки.
- `layout_1280x720.json`: реальные зоны текста, изображений и интерактивных действий.
- `layout_preview.webp`: иллюстративный композит, не скриншот из Godot и не runtime asset. Перстень взят из существующего каталога, цифры — пример текущего состояния.
- `manifest.json`: размеры и SHA-256 файлов.

## Визуальный канон V1.2
Пакет полностью заменяет V1 и V1.1, не смешивать файлы разных ревизий. Утверждены приглушённая бронза, образ Волшебника из действующего главного меню и единый кольцеобразный крестообразный герб с удлинённым шипованным древком. Для последующих артов использовать те же референсы: `assets/pixel/main/menu_v2/backdrop.webp` (образ Волшебника), `assets/pixel/travel/last_dressing_station/station_standard.png` и `assets/pixel/battle/arenas/approved_d283/firing_square.webp` (геральдика). Не заменять герб звёздами, башнями или произвольными эмблемами. Закрепить это в проектных документах/арт-реестре; не перерисовывать ранее утверждённые экраны без отдельного решения.

## Целевой режим и контракт
Только `reward_mode == "death_wager"` в `scripts/reward/reward.gd`. Использовать отдельное представление по аналогии с уже внедрёнными Normal Loot, Elite Trophy и Hero Development. Не менять логику _setup_death_wager_reward(), option_ids, pending_wager_artifact_id, выбор/резолв, экономику, сохранение, навигацию и порядок наград.

- Gold: id `gold`, +60 золота, утверждённый кроп кошеля.
- Relic: `artifact:<id>`, реальный title, description и изображение из ArtifactArtCatalog.get_reliquary_texture(id), с обрезкой прозрачных полей/вписыванием по существующему паттерну. Не вшивать «Перстень жатвы» и не фиксировать ID. Если реликвий не осталось: `fallback_gold`, «ПУСТОЙ ТАЙНИК», +50 золота, кроп кошеля вместо реликвии.
- Upgrade: `bonus_upgrade`, фактический прогресс доп. развития; переход к уже внедрённому выбору развития. Если лимит исчерпан: `extra_cap_gold`, «ЗАБРАТЬ ЗОЛОТО», +45 вместо усиления, кроп кошеля вместо свитка.
- Сохранить смысл предупреждения: специальная награда не погашает долг волшебнику. Обрабатывать обе ветки debt, не прятать причину или последствие. Если длинные реплики не помещаются, переносить строки и использовать живой footer для дополнительного пояснения/полной подсказки, не сокращая смысл.
- Заголовки, описания, кнопки — нативные элементы Godot, общие шрифты, костяной текст на тёмных поверхностях и тёмные чернила на пергаменте. Описания помещаются в соответствующие прямоугольники. Для длинных эффектов — перенос и компактный размер, при необходимости ограниченная прокрутка/полная подсказка. Не обрезать важные числа, отрицательные эффекты, ограничения.
- Реальная кнопка на каждом из трёх слотов. Допустим весь прямоугольник карты как hotspot; «ВЫБРАТЬ» — живой текст. Hover/focus/pressed — тонкая приглушённая бронза без неона, не масштабировать отдельную часть карты относительно неподвижной нарисованной рамки. Enter и мышь должны активировать ровно один существующий обработчик.
- Не оставлять старые DS3-панели, заголовки и фон на виду одновременно. Переиспользовать единственный имеющийся путь разблокировки/блокировки reward, корректно снять представление и подключить Hero Development при выборе bonus_upgrade. Сохранить feedback перед существующим переходом, не потерять сообщение после _finish_reward().
- Runtime target: `assets/pixel/ui/reward_death_wager_v12/`, source/provenance: `assets/source_archive/reward_death_wager_v12/`. Сохранить старые общие экраны для прочих reward modes.

## Минимальная QA
Нативная проверка 1280×720: нормальная тройка, все реликвии уже собраны (+50), лимит доп. развития (+45), активный долг; выбрать gold, relic и bonus_upgrade на изолированных сценариях. Проверить правильную выдачу, переход к существующему развитию, сохранение, единственный commit действия и возврат к столу. Можно использовать существующие QA маршруты. Проверить только изменённый экран и ближайшую зависимость, не запускать полный дорогостоящий sweep без необходимости. Сохранить основные фактические снимки. Не заявлять native PASS, если запуск не выполнен.
