# Combat Impact V2 · визуальный пилот

Откройте `scenes/dev/combat_impact_preview.tscn` через F6. В QA Hub тот же маршрут находится в **АНИМАЦИИ → Combat Impact V2 — Могильный звон**. Выберите **Classic** или **Impact V2**, затем нажмите **Начать бой**. Для сравнения оставьте исходные планы и расстановку. Кнопка **Повтор** заново собирает реальный Grave Bell с рыцарем, следопытом и магом и seed 418.

| Источник | Акцент |
| --- | --- |
| Рыцарь | Направленный костяно-бронзовый веер на цели. Для штатного `strong_hit` искры шире и заметнее. |
| Следопыт | Короткие светлые осколки в точке контакта стрелы. Длинного следа по D365 нет. |
| Маг | Фиолетовые искры и локальное кольцо заменяют прежнюю линию заклинания. Если удар нанёс урон дополнительной цели, одно низкое кольцо расходится от центра AoE. |
| Противники | Костяные осколки быстро оседают на фоне штатного D420 падения. Последний враг даёт более широкий акцент, после которого панель победы появляется через 0,20 с. |

Настройки пилота задаёт только QA-превью. Временные штрихи и кольца используют общий код Line2D и Tween. Результат, награда, урон и hit-stop рассчитываются существующим боем.

## Нативное сравнение

Кропы из Godot 4.7.2 при 1280×720. Верхний ряд — Classic, нижний — Impact V2. В каждом ряду показаны контакт, +3 и +6 кадров при 60 fps.

[Рыцарь](qa/combat_impact_v2/knight.png) · [Следопыт](qa/combat_impact_v2/ranger.png) · [Маг](qa/combat_impact_v2/mage.png) · [Гибель](qa/combat_impact_v2/death.png)

Два реальных боя совпали по начальным позициям, последовательности 33 попаданий, итоговым HP и золоту. Impact V2 открыл штатный экран награды. Группу временных контактных узлов проверили после завершения боя. Целевой GUT по BattleUnit и D365 — 10/10.
