# Run End Visual V2

Native Godot 4.7.2 captures at 1280×720 from the production RunEnd scene with isolated QA data.

- [Victory](victory.webp) · trio, 13 relics, long upgrade list, fractional damage bonus.
- [Defeat](defeat.webp) · solo Ranger, lost Mage, Knight not encountered, no relics, long reason and Last Deal payment, hunting token.
