# Death Wager Visual V1.2

Godot 4.7.2 rendered the production Reward and Table scenes at 1280×720. The fixture started at the victorious reward checkpoint and used isolated saves.

- [Normal offers with debt](wager-active-debt.webp) shows the pending relic and the full warning.
- [Gold alternatives](wager-fallbacks.webp) shows a full relic collection and capped extra development.
- [Bonus development](wager-bonus-development.webp) shows the existing next screen after choosing the wager upgrade.

Native checks covered mouse and keyboard, opening and closing the full description, and a duplicate gold activation. Gold (60), the pending relic, one extra upgrade, the empty cache (50) and the development cap (45) each saved the expected outcome and returned to Table through the existing route. Active debt persisted. The existing major development step also transitioned to the wager screen.

Godot emitted shutdown ObjectDB and resource diagnostics after the checks.
