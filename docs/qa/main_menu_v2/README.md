# Main Menu Visual V2

Native Godot 4.7.2 at 1280×720 with isolated profiles.

- [No save](menu_empty.webp): Continue disabled and skipped in keyboard navigation.
- [Valid save](menu_continue.webp): Continue restored the Table and the saved wallet.
- New Game opened the intro on an empty profile. With a save, the confirmation reset the Memory Glass and retained the Archive and backup.
- The Archive opened and returned via Esc. Exit closed the process.

The built-in image editor was directed to remove the left UI and only the middle card while preserving the Wizard, props and palette. A separate local edit removed button captions for the texture crops. The logo uses the approved reference pixels. [Art sources](../../../assets/source_archive/main_menu_v2/)
