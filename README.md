# Misdeal

A dark-fantasy card-driven roguelike with a compact tactical autobattler.

You play across a cursed tabletop controlled by an evil wizard. Cards create the adventure; combat encounters become short autobattles where preparation, positioning and party composition matter more than direct control.

## Current status

Early prototype.

The repository currently contains:
- a Godot 4.7.x project;
- a bootable main scene;
- project development rules in `AGENTS.md`;
- the initial game concept in `docs/CONCEPT.md`.

## Open in Godot

1. Clone this repository.
2. Open Godot Project Manager.
3. Import the folder containing `project.godot`.
4. Press Play.

## First milestone

A playable combat prototype:
- 3 heroes;
- 3 skeletons;
- pre-battle placement;
- automatic movement and attacks;
- health bars;
- victory / defeat;
- restart.
