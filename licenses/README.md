# Original third-party license evidence

Save unchanged original upstream LICENSE, NOTICE and per-asset license
evidence under an entry-specific subdirectory, referencing it from
`THIRD_PARTY_ASSETS.json`. Existing originals stay at their original paths:
`addons/gut/LICENSE.md` and `addons/gut/fonts/OFL.txt`. The initial
legacy registry is documented but incomplete; do not invent missing license
texts or treat this directory's existence as legal clearance.
