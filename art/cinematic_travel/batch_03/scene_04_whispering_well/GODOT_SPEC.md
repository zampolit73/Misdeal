# Шепчущий колодец · Travel V2

Плоскость 1280×720, sRGB, мастер WebP lossless. Альфа-слои PNG в координатах кадра. Контакт отряда вычисляется на квадратичной кривой A 126,659 → B 995,591 → C 1187,354, горизонт y=223, ближняя видимая высота 179px, ходьба ne, 6,5 fps при рабочей скорости.

Общий пан архитектуры и переднего плана 1,2 px/s с overscan 1,009. Передний план отсекает фигуры по готовому RGBA, архитектура не движется отдельно от постановочных предметов. Локальная дымка до 0,085 alpha допустима вне фокуса. Координаты на уровне подошв. Сортировка по y, затем слой foreground. Проверь края при изменении viewport.

Типовой переход 0–0,45 с, реакция 0,45–1,20 с, нарратив около 0,92 с, выход с 3,40 с. Передача mage в 1.12 с, место NPC 488,363, ноги при вступлении 588,525, слияние с путём около 848,557. Свой слой для NPC и для идущей фигуры. В каждом кадре виден только один экземпляр.

Фазы `layers/entry.png`, `layers/sink.png`. Найм мага после захвата роли и подтверждения изменения отряда. В leave_lost профиль мага опускается под кромку в 1,38–2,45 с. В остальных ветках лампа на месте, объект меняется только у кромки.
