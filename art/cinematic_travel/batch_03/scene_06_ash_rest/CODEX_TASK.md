# Codex · Пепельный привал

Выполняй после утверждения партии по [общему заданию](../CODEX_BATCH_03.md). Для `ash_rest` проверь исходный резолвер и используй `manifest.json`. Сохранить CASTLE_FACT_MARCH в существующем порядке _finish. Ветки loot/abandon закрывают судьбу Ranger без удаления уже активного героя.

До 1,03 с следопыт сидит на краю. Recruit переводит его в идущий отряд и немного разжигает угли. Loot открывает пустые ремни. Abandon оставляет припасы рядом с сидящим.

Прогони 7 исходов `recruit`, `loot`, `abandon`, `knight`, `ranger`, `mage`, `leave` с допустимыми составами и проверкой однократных наград. Сними 0,65 / 1,15 / 2,50 с и проверь завершение V2 через Table. Сохрани контрольные суммы поставленных файлов.
