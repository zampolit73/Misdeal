# Пепельный привал · Travel V2

Плоскость 1280×720, sRGB, мастер WebP lossless. Альфа-слои PNG в координатах кадра. Контакт отряда вычисляется на квадратичной кривой A 107,628 → B 658,617 → C 1175,531, горизонт y=221, ближняя видимая высота 176px, ходьба ne, 6,5 fps при рабочей скорости.

Общий пан архитектуры и переднего плана 1,2 px/s с overscan 1,009. Передний план отсекает фигуры по готовому RGBA, архитектура не движется отдельно от постановочных предметов. Локальная дымка до 0,085 alpha допустима вне фокуса. Координаты на уровне подошв. Сортировка по y, затем слой foreground. Проверь края при изменении viewport.

Типовой переход 0–0,45 с, реакция 0,45–1,20 с, нарратив около 0,92 с, выход с 3,40 с. Передача ranger в 1.03 с, место NPC 515,527, ноги при вступлении 535,533, слияние с путём около 759,592. Свой слой для NPC и для идущей фигуры. В каждом кадре виден только один экземпляр.

Фазы `layers/entry.png`. До 1,03 с следопыт сидит на краю. Recruit переводит его в идущий отряд и немного разжигает угли. Loot открывает пустые ремни. Abandon оставляет припасы рядом с сидящим.
