# Матрица исходов Batch 03

Снимок `5b6454b10325cc35bacc2754da8a84338040ffab`. Роль с префиксом `+` входит в выходящую группу после успешного найма. `lost` закрывает возможность найма и сохраняет состав активной группы. `same` сохраняет существующие роли и спутника. У Колодца choice ID соответствует смыслу трёх отдельных обработчиков, а не полю сохранения.

Для ролевых развитий нужен свободный общий лимит и доступный следующий upgrade указанной роли. Для наименее развитого используется текущий порядок `get_least_developed_extra_role()`. RNG реликвии использует уже существующий `add_random_available_artifact()`. У `faceless_card` исходы профилей запускаются из `_resolve_leave()`. Обычный `leave` никогда не домысливает награду.
