# Чёрный алтарь · Travel V2

Плоскость 1280×720, sRGB, мастер WebP lossless. Альфа-слои PNG в координатах кадра. Контакт отряда вычисляется на квадратичной кривой A 106,643 → B 659,638 → C 1172,628, горизонт y=293, ближняя видимая высота 184px, ходьба side, 6,5 fps при рабочей скорости.

Общий пан архитектуры и переднего плана 1,2 px/s с overscan 1,009. Передний план отсекает фигуры по готовому RGBA, архитектура не движется отдельно от постановочных предметов. Локальная дымка до 0,085 alpha допустима вне фокуса. Координаты на уровне подошв. Сортировка по y, затем слой foreground. Проверь края при изменении viewport.

Типовой переход 0–0,45 с, реакция 0,45–1,20 с, нарратив около 0,92 с, выход с 3,40 с. Передача mage в 1.02 с, место NPC 1054,337, ноги при вступлении 1076,572, слияние с путём около 1166,635. Свой слой для NPC и для идущей фигуры. В каждом кадре виден только один экземпляр.

Фазы `layers/entry.png`. До 1,02 с возможен лежащий маг. После handoff в кадре есть только актёр мага из подтверждённого состава. Ветку abandon_loot держать на лежащем NPC. Угольный акцент приглушён после спасения.
