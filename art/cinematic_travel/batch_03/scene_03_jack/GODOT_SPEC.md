# Джек · Travel V2

Плоскость 1280×720, sRGB, мастер WebP lossless. Альфа-слои PNG в координатах кадра. Контакт отряда вычисляется на квадратичной кривой A 128,659 → B 963,630 → C 1198,441, горизонт y=264, ближняя видимая высота 171px, ходьба ne, 6,5 fps при рабочей скорости.

Общий пан архитектуры и переднего плана 1,2 px/s с overscan 1,009. Передний план отсекает фигуры по готовому RGBA, архитектура не движется отдельно от постановочных предметов. Локальная дымка до 0,085 alpha допустима вне фокуса. Координаты на уровне подошв. Сортировка по y, затем слой foreground. Проверь края при изменении viewport.

Типовой переход 0–0,45 с, реакция 0,45–1,20 с, нарратив около 0,92 с, выход с 3,40 с. Передача jack в 1.16 с, место NPC 379,523, ноги при вступлении 408,529, слияние с путём около 650,635. Свой слой для NPC и для идущей фигуры. В каждом кадре виден только один экземпляр.

Фазы `layers/entry.png`, `layers/treatment.png`. 0,63–1,16 с видна повязка. В 1,16 с лежащий пёс скрывается, собака движется к Ranger и остаётся за его ногой. В token жетон исчезает с ошейника, в passed остаётся. Jack использует один отдельный актёр, вне массива party_roles.
