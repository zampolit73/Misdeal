# Карта без лица · Travel V2

Плоскость 1280×720, sRGB, мастер WebP lossless. Альфа-слои PNG в координатах кадра. Контакт отряда вычисляется на квадратичной кривой A 115,641 → B 661,657 → C 1160,653, горизонт y=306, ближняя видимая высота 169px, ходьба side, 6,5 fps при рабочей скорости.

Общий пан архитектуры и переднего плана 1,2 px/s с overscan 1,009. Передний план отсекает фигуры по готовому RGBA, архитектура не движется отдельно от постановочных предметов. Локальная дымка до 0,085 alpha допустима вне фокуса. Координаты на уровне подошв. Сортировка по y, затем слой foreground. Проверь края при изменении viewport.

Типовой переход 0–0,45 с, реакция 0,45–1,20 с, нарратив около 0,92 с, выход с 3,40 с. Выбор меняет локальный слой около 0,84 с.

Фазы без дополнительных входных слоёв. Край карты раскрывается из той же точки на бархате. Монеты, пустое лицо, рубцы, две плоские фигуры и обгоревшие фрагменты не становятся NPC и не попадают в инвентарь. Свёрток только для выданной реликвии.
