# Codex · Карта без лица

Выполняй после утверждения партии по [общему заданию](../CODEX_BATCH_03.md). Для `faceless_card` проверь исходный резолвер и используй `manifest.json`. Существующий randi_range(0,2) вызывается один раз. Записать результат присвоением action внутри той же ветки. Экономические fallback, долг и профили различаются по успешному результату.

Край карты раскрывается из той же точки на бархате. Монеты, пустое лицо, рубцы, две плоские фигуры и обгоревшие фрагменты не становятся NPC и не попадают в инвентарь. Свёрток только для выданной реликвии.

Прогони 15 исходов `reveal_gold`, `reveal_relic`, `reveal_relic_empty`, `reveal_upgrade`, `reveal_upgrade_empty`, `bribe`, `bribe_scar`, `burn_debt`, `burn_gold`, `witnessless`, `scarred_relic`, `scarred_empty`, `riskbound_upgrade`, `riskbound_empty`, `leave` с допустимыми составами и проверкой однократных наград. Сними 0,65 / 1,15 / 2,50 с и проверь завершение V2 через Table. Сохрани контрольные суммы поставленных файлов.
