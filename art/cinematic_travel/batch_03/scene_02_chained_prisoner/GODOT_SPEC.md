# Закованный пленник · Travel V2

Плоскость 1280×720, sRGB, мастер WebP lossless. Альфа-слои PNG в координатах кадра. Контакт отряда вычисляется на квадратичной кривой A 96,625 → B 694,658 → C 1172,657, горизонт y=271, ближняя видимая высота 194px, ходьба side, 6,5 fps при рабочей скорости.

Общий пан архитектуры и переднего плана 1,2 px/s с overscan 1,009. Передний план отсекает фигуры по готовому RGBA, архитектура не движется отдельно от постановочных предметов. Локальная дымка до 0,085 alpha допустима вне фокуса. Координаты на уровне подошв. Сортировка по y, затем слой foreground. Проверь края при изменении viewport.

Типовой переход 0–0,45 с, реакция 0,45–1,20 с, нарратив около 0,92 с, выход с 3,40 с. Передача knight в 1.04 с, место NPC 877,546, ноги при вступлении 881,571, слияние с путём около 1053,651. Свой слой для NPC и для идущей фигуры. В каждом кадре виден только один экземпляр.

Фазы `layers/entry.png`. Решётка переключается только после открытия, корпус камеры остаётся на той же плоскости. Успешный найм начинает ходьбу у порога. Наставник остаётся отделён в глубине, затем теряется в тени. При существующем Knight в отряде не дублировать его одежду и силуэт в проходе. Использовать затенённый позовой слой как стадию внутри камеры.
